# مصروفات المواقع — Web

واجهة نظام فواتير مشتريات المواقع. صفحة static (HTML + JavaScript) بتكلم Supabase مباشرة،
والصلاحيات كلها متطبقة في الـ database (RLS)، فالـ publishable key اللي في `app.js` آمن يكون في المتصفح.

- **Backend:** Supabase project `site-expenses` (ref `hmqceajdhnvkzceifewb`)، والكود بتاعه في repo/zip منفصل (migrations + Edge Functions `ingest` و`admin-users`).
- **Hosting:** GitHub Pages من الـ branch `gh-pages`.

## الشاشات
| الدور | الشاشات |
| --- | --- |
| مهندس | فاتورة جديدة (تصوير + قراءة QR على الموبايل)، فواتيري + رصيد العهدة، حسابي |
| محاسب | المراجعة، كل الفواتير + تصدير CSV، العُهد، المصروفات حسب المشروع، حسابي |
| أدمن | كل اللي فوق + الإعدادات (مستخدمين، مشاريع، تعيين مهندسين، أكواد GL) |

## أول تشغيل
من صفحة الدخول اضغط **أول تشغيل؟** واكتب كود التشغيل الأول اللي اتبعتلك، فيتعمل أول حساب أدمن.
الكود بيشتغل مرة واحدة وبس، وطول ما مفيش أدمن. باقي الحسابات بيعملها الأدمن من الإعدادات.
